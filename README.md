\# CarryLink



CarryLink is a C2C marketplace that connects travelers from Japan to Hong Kong with people who want to purchase products from Japan.



\## Project Status



MVP Development



\## Target Route



Japan → Hong Kong



\## Purpose



To utilize unused baggage capacity for proxy purchasing.



\## Technology



\### Frontend

\- Next.js

\- TypeScript



\### AWS

\- Amazon Cognito

\- API Gateway

\- AWS Lambda

\- Amazon DynamoDB

\- Amazon S3



\### Payment

\- Stripe Test Mode
